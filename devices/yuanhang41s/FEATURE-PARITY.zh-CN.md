样机已完成保数据永久安装与正常重启验证；源码已接入安装/打包入口，正式包尚未构建。

| 功能 | 接入情况 / 实机证据 |
| --- | --- |
| 主题、看板、双卡查看、APN、频段/小区、AT、流量池、短信转发 | SIM2 上网确认；真实 APN 草稿增改删、双卡流量套餐隔离和屏幕同步通过；短信实收发按用户要求跳过 |
| 屏幕、触摸、锁屏、导航 | 用户确认正常；真实 evdev 手势/息屏触控与电源键唤醒、真实 API 页面导航通过；720×1600 基础缩放 2 倍 |
| 提示音、铃声与音量 | 原厂 AW883xx ACF、IIS3 路由；用户确认长音和短短信音正常 |
| 听筒/通话外放/蓝牙通话 | 数字 PA 专属接线已接入共享通话服务；用户要求通话实测留待后续 |
| 蓝牙管理、扫描、配对入口 | 补齐 sprdbt_tty 自动加载；hci0 注册、上电和附近设备扫描通过；配对/音频待测 |

音频、触摸、偏压、充电芯片等外设配置只在本机 profile 生效。
公共 CPU 后端新增的是本机已核验固件哈希，不放宽未知固件检查。
`e5-at` 的已适配机型分流补入本机，交互/采集使用现有 nr2/6/7 队列，
短信事务继续由 ModemManager 持有，不把所有请求挤到拨号端口。
两次调压验证后，卡 2 已自动恢复蜂窝连接；设备外网 3 次探测无丢包。
网页充电管理已实际停充/恢复并保留 USB 管理连接；不将它等同于充电器实测。
当前默认 OpenWrt A；Android B 与备份保留，基带使用本机固件及隔离 NV。
