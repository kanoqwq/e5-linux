# OpenWrt Tools for Android

同一个 Android 控制端支持 E5 系列和 MU300 系列的完整发行包。安装器、
Diff Studio、补丁更新器、版本摘要生成器通过手机底部导航或平板左侧导航切换。
适用 Android 8.0 及以上的 ARM64 手机；原生库同时检查 4 KiB/16 KiB
页面兼容所需的 LOAD 对齐。控制手机不需要 root。

## 连接与安装

1. 在手机安装 `OpenWrt-Tools.apk`，打开安装器并查看新手指引和帮助。
2. 导入完整 ZIP，或选择已解压的安装包目录。不要只选择 EXE 或 boot。
3. 用 OTG 数据线连接目标随身 WiFi，在手机授权 USB 访问，并在目标
   Android 授权当前控制端的 ADB 密钥。拒绝后可点“刷新设备”重新请求。
   也可使用目标设备的无线 ADB 地址 `IP:5555`。
4. 目标仍须按原流程提供 root/su。查看安装计划和空间分配后，再确认开始。
   TF、内置分区、镜像、在线缩容、格式化后备和两阶段续装共用桌面事务。
5. 重置 Android 后，重新设置目标的 USB 调试与 root，回到续装入口继续。
   前台通知可用于返回正在运行的任务；拒绝通知权限不会自动改动设备设置。

更新已运行的 OpenWrt 时，填写它的管理地址和 root 密码，通过 SSH 更新。
高级选项保留重装、卸载归还空间和实验性 userdata 镜像入口；实际可用性
与目标发行包和设备状态有关，格式化始终需要原有确认流程。

## 备份与恢复

备份、安装记录和 ADB 身份保存在 App 私有空间。可在安装器中导出恢复
备份，或展开“关于与备份”打开 Android 文档界面。该文档入口只读，
不公开 ADB 私钥。卸载本 App 会删除私有记录，请先将恢复备份导出到文档。

其他控制端导出的完整恢复 ZIP 可以导入手机。工具会重定位主记录及旧安装记录中的
原控制端路径，不修改备份的分区字节；设备身份、备份和容量检查仍由共用后端
执行。导入完成后清理 App 内的临时解压副本，原始 ZIP 不会被删除。

首页和“关于与备份”可进入“安装记录管理”，查看、搜索、导入、导出及删除
记录，并显示记录与备份占用的空间。删除需要再次确认，仅移除本机对应的
记录及其备份，不卸载目标系统；正在使用的记录不能删除。重要恢复备份请
先导出，避免在删除记录或卸载本 App 后失去续装、恢复和归还空间的资料。

## Diff Studio 与补丁更新

旧版可选择完整 ZIP 或版本摘要 JSON，新版选择完整 ZIP。分析后可修改
默认输出名称。导出的 ZIP 包含一份 `update.ota`、本机安装的 APK，以及
新版发行包中经散列核对的电脑更新器，复用同一份载荷和桌面运行库。

手机补丁更新页可导入原始 OTA，或含一份 `update.ota` 的 ZIP，然后通过
SSH 检查和更新目标。网页系统补丁插件仍可使用同一份 OTA。
版本摘要页自动识别完整 ZIP、已解压目录及原始 rootfs；目录集合可选
1/2/4/8 个线程批量分析并导出摘要 ZIP。单个输入导出 JSON；原始 rootfs
还可提供可选的旧 boot，沿用原 CLI 的身份与散列规则。

## 当前验收范围

共享后端、主机协议和移动布局有自动回归；已有真实 Android 模拟器的
JNI/Python、合成 MU300 包分析、摘要等价分析、导出和页面切换报告。
这些记录不代表 TF/分区/NV 的真实设备刷写通过。实际刷写、卸载与 NV
操作需要目标设备用户明确授权；当前控制端测试不会自动执行它们。

无线 ADB 对齐已有 IP:5555 流程，尚不包含手机开发者选项的配对码/TLS
配对入口。Android 可能结束后台进程，安装器依赖已落盘事务恢复，不把
前台服务当作绝不会被结束的保证。

构建、签名及当前进度见 `docs/ANDROID-INSTALLER-PORT.zh-CN.md`。
