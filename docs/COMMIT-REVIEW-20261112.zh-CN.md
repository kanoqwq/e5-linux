## 发现并处理的问题

版本锁已指向 `openwrt-tools@328c62d`，但对应的公开 Release 此前没有发布。
本机显式选择原生安装器缓存时能够打包，干净环境按锁下载则会失败。

用户授权后，已将现成的三个经过验证的原生安装器输入归档发布至：

https://github.com/kanoqwq/openwrt-tools/releases/tag/build-tools-328c62d

GitHub 返回的三份资产 SHA-256 与 E5、MU300、Pro 的锁文件逐项一致；
没有回退安装器提交，也没有改写摘要以接受旧二进制。
此问题不影响已包含完整安装器的本地固件 ZIP。

源码复核及下列回归未发现新的、可确认的运行逻辑回归。
NFQUEUE 是内核接口支持；没有因此内置代理或 VPN 程序。
